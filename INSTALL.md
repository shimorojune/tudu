# Install Daily TODO (macOS)

## Quick install

1. Unzip `Daily-TODO-macOS-v2.0.0.zip`
2. Drag **Daily TODO.app** to Applications
3. Right-click → **Open** on first launch (macOS security)
4. Complete **JIRA setup** in Settings (or skip for now)

## Requirements

- macOS 10.15 or later
- Apple Silicon Mac (arm64)

## First launch

The app runs in your menu bar. Close the window to hide it — the app keeps running.

- **Tray icon** → click to show/hide the main window
- **Settings** → connect JIRA, set poll and reminder intervals
- **Check in now** → trigger a task reminder

## JIRA credentials

See [README.md](README.md) for Cloud vs Server setup.

Your credentials are stored locally at:

`~/Library/Application Support/com.tudu.dailytodo/config.json`
