# Chunk 10 · Jira · test cases

Status column is kept by `pnpm test:status` in [STATUS.md](STATUS.md). Run this chunk's tests with
`pnpm test -- --project ui --project core --project client --project web --project server` and `pnpm e2e jira`.
End-to-end tests fix the clock at Sunday 18 October 2026, 10:00 and connect to the fake Jira the test API serves at
`/__test/jira` (TEST_ROUTES): tokens starting `good-` read, `noread-` can't read issues, anything else is refused;
`POST /__test/jira/expire` and `/down` make a token stop working or Jira stop answering.
