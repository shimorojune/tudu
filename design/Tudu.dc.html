Tudu / macOS redesign

Light ground, ink type, red kept for one primary action and the JIRA tether. The date says when; the bucket says whether today — Now is committed, Next is queued behind it, Later is first to slip. Now caps at five, so adding one means dropping one. Undated work waits in Unscheduled, never in a day’s Later. Work lives in a space — Personal by default, or an organization you create or join — and a task stays in the space it was made in. Co-workers read each other’s lists; editing one is a right you grant person by person, and even then nothing enters a day unasked: new tasks and proposed edits both wait in Requests. Every change is written to the task’s timeline. Boards below: foundations, daily use, task entry, quick add, organizations & co-workers, setup & system, coding agents.

1.3 What changed, and why five things the shipped preset file gets wrong · left is today, right is proposed
GitHub had no light mode The preset mapped light: modernistLight, so picking GitHub in light mode changed nothing at all. It now has its own cool ground, warmed a touch so the red doesn’t turn acid against it.
→
A stray blue in Current’s dark sidebar --sidebar-primary was oklch(0.4882 0.2172 264) — a saturated shadcn blue left behind by the generator, appearing nowhere else in the theme. Gone with the preset.
→
The settings chip lied Current’s preview swatch advertised olive #8b6914 while its actual primary was a muted brown. Swatches are now read from the preset itself, so a chip can never drift from what it applies.
→
Identity flipped between modes Current drew a brown button in light and a pale cream one in dark — switching appearance changed the brand, not just the lighting. Red is now constant across every preset and both modes; only the ground moves.
→
Red as type never passed One red did both jobs: a fill behind white, and small type like Slipping 4 directly on the ground — where #ec3013 reads about 3.6:1. The fill keeps the bright red; a paired --primary-text carries type at 4.5:1 or better. Note the fill has its own ceiling: white on #ec3013 is 4.15:1, so a red button carries a label at 14px and up, not at 11px.
→
Current is cut With one red everywhere, Current had no corner left — it was pure grey, which is Neutral’s job. Three presets, each owning one axis: warm stone, cool slate, pure grey. Stored preferences reading "current" map to Modernist — the house style and the closest in intent.

4.4 What changed from the shipped bar
Four labelled rows became one DAY / BUCKET / TIMING / PROJECT gave a capture bar the shape of a form, and the label column took 90px to say what the chips already say. The chips carry their own value, so the labels go.
The input is the only large thing 21px against 12px chips. Invoked with ⌘⇧T you should be able to type and press ↵ without reading anything else on the panel.
It says where the task will land “Lands in Today · Next” in the footer. The shipped bar showed state only as selected chips, which you have to decode; a sentence is checkable at a glance.
Timing left; typed tokens arrived Start and Due were buttons with no value showing — two more taps for something rarely set at capture time. Set them in the task, or type /tmr, !now, #EGS inline. A pasted JIRA key links itself.
One “None” meant two things It appeared under both DAY and PROJECT. Now it reads Unscheduled for the day and No project for the sticker — and the panel follows the theme rather than being fixed dark.
